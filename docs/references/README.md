# 原始材料说明

本目录保留用户提供的两份课程材料，作为课程要求的依据：

- 学生需求分析与AI智能体使用验证报告.md：报告编写与验证要求，含空表和教学模拟示例；**不是本组已经完成的需求分析**。
- 实践项目说明.pdf：贯穿式课程项目与可选专业项目说明。

本次选定方向由用户指定为“专业领域的智能客服或校园事务问答系统”。材料中的其他项目和图书借阅示例不自动成为本项目需求。后续本组确认的需求放 docs/requirements/；不直接在原始模板里填写已完成结果。

原件从本地用户提供文件复制，初始化时保留内容不变。后续如课程材料更新，记录新来源与日期，并核对受影响的需求或报告。
